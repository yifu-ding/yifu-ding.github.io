Recent Papers

A survey of low-bit large language models: Basics, systems, and algorithms

Ruihao Gong, Yifu Ding, Zining Wang, Chengtao Lv, Xingyu Zheng, Jinyang Du, Haotong Qin, Jinyang Guo, Michele Magno, Xianglong Liu

Neural Networks

PDF BibTex

This survey systematically reviews low-bit quantization for large language models, covering core principles, data formats, system and framework support, and algorithmic methods for efficient training and inference. It highlights how low-bit techniques reduce memory and computation costs while preserving performance, and discusses open challenges and future research directions.

DA-KD: Difficulty-Aware Knowledge Distillation for Efficient Large Language Models

Changyi He, Yifu Ding, Jinyang Guo, Ruihao Gong, Haotong Qin, Xianglong Liu

ICML 2025

PDF BibTex

DA-KD cuts distillation cost by dynamically selecting training samples based on difficulty, avoiding wasted effort on easy examples. It also introduces bidirectional discrepancy loss to stabilize optimization and learn better from hard samples, achieving 2% accuracy gain with half training cost and around 4.7x compression.

Dynamic Parallel Tree Search for Efficient LLM Reasoning

Yifu Ding, Wentao Jiang, Shunyu Liu, Yongcheng Jing, Jinyang Guo, Yingjie Wang, Jing Zhang, Zengmao Wang, Ziwei Liu, Bo Du, Xianglong Liu, Dacheng Tao

ACL 2025

PDF Code BibTex

DPTS accelerates Tree of Thoughts reasoning by reducing redundant exploration and frequent focus switching during search. It introduces a parallelism streamline that enables flexible multi-path generation via cache management and alignment, plus a search and transition mechanism to filter candidates and keep the search focused. Experiments on Qwen-2.5 and Llama-3 show 2 to 4× speedup with comparable or better accuracy.

VORTA: Efficient Video Diffusion via Routing Sparse Attention

Wenhao Sun, Rong-Cheng Tu, Yifu Ding, Zhao Jin, Jingyi Liao, Shunyu Liu, Dacheng Tao

NeurIPS 2025

PDF Code BibTex

VORTA accelerates video diffusion transformers by using sparse attention for long-range dependencies and routing to replace full 3D attention with specialized sparse variants. It achieves 1.76× end-to-end speedup on VBench without quality loss, and composes with other methods to reach up to 14.41× speedup.

Unlocking the Potential of Lightweight Quantized Models for Deepfake Detection

Renshuai Tao, Ziheng Qin, Yifu Ding, Chuangchuang Tan, Jiakai Wang, Wei Wang

IJCAI 2025

PDF Code BibTex

This work targets real-time edge deepfake detection via a low-bit quantization framework. A Connected Quantized Block captures shared forgery features while preserving method-specific textures via shortcuts. A Shifted Logarithmic Redistribution Quantizer improves near-zero activation quantization. Results show 10.8× compute and 12.4× storage reduction with strong accuracy, even beating some SOTA under 5% FLOPs.

QVGen: Pushing the Limit of Quantized Video Generative Models

Yushi Huang, Ruihao Gong, Jing Liu, Yifu Ding, Chengtao Lv, Haotong Qin, Jun Zhang

ICLR 2026

PDF Code BibTex

QVGen enables extremely low-bit (4-bit or below) quantization-aware training for video diffusion models, where naive quantization fails. It stabilizes QAT by reducing gradient norms with auxiliary modules that absorb quantization error, then removes their inference overhead via rank-decay using repeated SVD and rank regularization. Experiments show near full-precision quality at 4-bit and strong 3-bit gains on VBench.
